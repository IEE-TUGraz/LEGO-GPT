helper_functions.copy_default_config(config_path: str = 'config.yml', default_config_path: str = 'config_template.yml') → None

Copies a default configuration file to a specified path if it does not already exist.

Parameters:

  • config_path (str) – The path where the configuration file should be created. Defaults to “config.yml”.

  • default_config_path (str) – The path to the default configuration template file. Defaults to “config_template.yml”.

Behavior:

  • If the file at config_path does not exist, the function reads the content of default_config_path and writes it to config_path.

helper_functions.extract_excel_to_dataframe(input_dir: str, table: str) → DataFrame | tuple

Extract data from Excel files into a pandas DataFrame based on the specified table type. This function processes various Excel files and sheets, extracting and transforming data into pandas DataFrames according to the provided table parameter. The function supports multiple table types, each corresponding to a specific data extraction and transformation logic.

Parameters:

  • input_dir (str) – The directory containing the input Excel files.

  • table (str) –

    The type of table to extract. Supported values are:

    • ”i”: Extracts data from “Power_BusInfo.xlsx”.

    • ”rp”: Extracts unique values from “Power_WeightsRP.xlsx”.

    • ”k”: Extracts unique values from “Power_WeightsK.xlsx”.

    • ”gi”: Combines data from multiple Excel files (“Power_VRES”, “Power_ThermalGen”, “Power_Storage”, “Power_RoR”) into a DataFrame with columns “g” and “i”.

    • ”vLineP”: Processes line data from “model.xlsx” (sheet “vLineP”) and returns two DataFrames: one for the main data and one for line tuples.

    • ”coords”: Extracts coordinates (longitude and latitude) from “Power_BusInfo.xlsx”.

    • ”vGenP”: Processes generator data from “model.xlsx” into a long-format DataFrame.

    • ”pPmax”: Extracts power network data from “Power_Network.xlsx”.

    • ”pDemand”: Placeholder for future implementation.

Returns:

  • For most table types, returns a single DataFrame containing the extracted data.

  • For “vLineP”, returns a tuple of two DataFrames: (main data, line tuples).

  • For “gi”, returns a tuple of two DataFrames: (main data, unique “g” values).

  • Returns None if the table type is invalid or not yet implemented.

Return type:

pandas.DataFrame or tuple

Note

  • The function uses hardcoded file and sheet names for specific table types.

  • Some table types include additional preprocessing steps, such as removing duplicates or resetting the index.

Raises:

  • FileNotFoundError – If the specified Excel files or sheets are not found.

  • ValueError – If the table type is invalid or not supported.

plot_definitions.filter_dataframe(self, attr_str: str, rp: str, scope: str, local_node: str = None, local_line: str = None, k_range: list = []) → DataFrame

Filters a DataFrame based on the provided attributes, scope, and conditions.

Parameters:

  • attr_str (str) – The attribute string specifying which DataFrame to filter. Options include “vGenP”, “pDemandP”, and “vLineP”.

  • rp (str) – The representative period to filter by, applicable when long_format is False.

  • scope (str) – The scope of filtering. Options include “Local” and “Global”. - “Local”: Filters data specific to a local node or line. - “Global”: Aggregates data globally (only applicable for “pDemandP”).

  • local_node (str, optional) – The local node identifier for filtering when scope is “Local”. Defaults to None.

  • local_line (str, optional) – The local line identifier for filtering when scope is “Local”. Defaults to None.

  • k_range (list, optional) – A list of k values to filter the DataFrame by. Defaults to an empty list.

Returns:

The filtered DataFrame based on the specified conditions.

Returns None if the specified DataFrame is not available.

Return type:

pd.DataFrame

Note

  • The method operates on different DataFrames (vGenP, pDemandP, vLineP) based on attr_str.

  • If long_format is False, the DataFrame is filtered by the representative period (rp).

  • For “pDemandP” with “Global” scope, the data is aggregated by summing over k values.

  • For “vGenP” with “Local” scope, filtering is based on the local node’s group (g).

  • For “vLineP” with “Local” scope, filtering is based on the local line identifier.

ui_handler.generate_dynamic_plot(self, x_axis: str, y_axis: str, line_idx: str, node_idx: str, selected_period: str, scope: str, time_range: list) → Div

Generates a dynamic plot based on the provided parameters. :param x_axis: The variable to be used for the x-axis. Options include “time”, “generator”, or “line”. :type x_axis: str :param y_axis: The variable to be used for the y-axis. Options include “demand”, “dispatch”, or “power_flow”. :type y_axis: str :param line_idx: The str(index) of the line to be used for local power flow plots. :type line_idx: str :param node_idx: The index (str) of the node to be used for local dispatch or demand plots. :type node_idx: str :param selected_period: The selected period for filtering the data. :type selected_period: str :param scope: The scope of the plot, either “Global” or “Local”. :type scope: str :param time_range: A 2-element list specifying the range of time steps [start, end] for the plot. :type time_range: list

Returns:

A Dash HTML Div containing the generated plot as a dcc.Graph component.

Return type:

html.Div

Note

  • The function dynamically filters the data based on the provided parameters and generates a plot using Plotly.

  • The plot type and configuration depend on the combination of x_axis and y_axis values.

  • If the combination of x_axis and y_axis is invalid, a placeholder scatter plot is generated.

  • The layout of the plot is customized with specific margins, background colors, and font sizes.

ui_handler.generate_node_layer(buses: DataFrame, gi: DataFrame, vGenP_filtered: DataFrame, vSOCP_cii_filtered: DataFrame, js_generator: object, technology_colors: dict, cluster_options: dict) → GeoJSON

Generates a GeoJSON layer for visualizing nodes with pie chart plots based on input data. :param buses: DataFrame containing bus information, including latitude and longitude. :type buses: pd.DataFrame :param gi: DataFrame containing generator information, including connected bus and technology type. :type gi: pd.DataFrame :param vGenP_filtered: Filtered DataFrame containing generation data to be visualized. :type vGenP_filtered: pd.DataFrame :param vSOCP_cii_filtered: Filtered DataFrame containing voltage data for the selected time. :type vSOCP_cii_filtered: pd.DataFrame :param js_generator: Object providing JavaScript functions for customizing point and cluster layers. :type js_generator: object :param technology_colors: Dictionary mapping technology names to their corresponding colors. :type technology_colors: dict

Returns:

A Dash Leaflet GeoJSON layer with clustered nodes and pie chart visualizations.

Return type:

dl.GeoJSON

Notes

  • The function merges and processes the input data to prepare it for visualization.

  • Rows with missing latitude, longitude, or zero total values are skipped.

  • The resulting GeoJSON layer supports clustering and custom rendering of points and clusters.

  • The size scaling is based on total generation values, with a minimum size defined by the user.
