Adding Data - Contribution Guide

This tutorial explains how to contribute new data to the project using code and visuals. Each step is accompanied by a screenshot for clarity.

Step 1: Open the config.yml File

Navigate to the config.yml file, where plot and data selection are configured.

If your new plot requires additional data, add the name of the new table (as defined in the Pyomo model) to the tables section. Then, specify the x- and y-axis data for the plot in the dropdown-options section. This enables users to select the new data when generating plots.

In the get_data() function of the data loader module, adapt your table if necessary. In the example below, the table vStIntraRes is enhanced by adding information about which node each storage unit is attached to.

Step 3: Define the New Plot

In the plot_definitions.py file, define your new plot in the generate_plot(..) function using the newly added data. Start by extending the block that filters the data to be plotted. Then, add your plot to the list of plot definitions.

In the filter_dataframe(..) function, define how your data is filtered based on the selected x- and y-axis values. Here you can include any additional logic required for filtering your new table.

Step 4: Test the Integration

Run a minimal example or use the user interface to verify that the plot is generated correctly with the new data.

Next Steps

Once the new table is added, documented, and tested, feel free to open a pull request.

Please ensure the following before submitting:

  • The table name follows existing naming conventions.

  • All fields are clearly documented.

  • No hard-coded paths or values are introduced.

  • The new data is compatible with the plot selection logic.
